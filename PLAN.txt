│ 過緩和法ソルバー                                                                                                                │
│                                                                                                                                 │
│ def solve_temperature(state, omega=1.2, eps=0.01, max_iter=5000):                                                               │
│     for iteration in range(max_iter):                                                                                           │
│         max_change = gauss_seidel_sweep(state, omega)                                                                           │
│         if max_change < eps:                                                                                                    │
│             return iteration                                                                                                    │
│     return max_iter                                                                                                             │
│                                                                                                                                 │
│ 検証方法                                                                                                                        │
│                                                                                                                                 │
│ 1. 単体テスト: 各熱力学関数を既知の値と照合                                                                                     │
│ 2. 往復テスト: rewpt ↔ wptre が逆関数であることを確認                                                                           │
│ 3. Fortran照合: 同一入力で両バージョンを実行、出力比較                                                                          │
│ 4. 保存則: 水分・熱量の収支バランス検証                                                                                         │
